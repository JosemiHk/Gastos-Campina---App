# Campiña Design Language

## Vision

Campiña should feel simple, trustworthy, modern and calm.

The application is designed for household management, not corporate finance.

The experience should be lightweight, clean and easy to understand.

---

# Visual Inspiration

- Material Design 3
- Google Home
- Google Finance
- Notion

Keywords:

- Household
- Simplicity
- Transparency
- Clarity
- Calm Technology
- Aurora Forest

---

# Layout Principles

- Mobile First
- Large whitespace
- Comfortable spacing
- Responsive layouts
- No visual clutter

Prioritize readability over information density.

---

# Components

## Cards

Primary UI element.

Characteristics:

- White surfaces
- Soft shadows
- Rounded corners
- Spacious padding

---

## Buttons

Primary actions:

- Solid primary color
- High contrast
- Medium emphasis

Secondary actions:

- Outlined style
- Minimal visual weight

---

## Forms

Use Material Design 3 patterns.

Requirements:

- Clear labels
- Large touch targets
- Accessible spacing

---

# Typography

Use Inter.

Hierarchy should be clean and highly readable.

Important numbers and totals should receive strong visual emphasis.

---

# Color Philosophy

Use green tones as a brand identity, not as decoration.

The interface should remain predominantly neutral and light.

Accent colors should be used sparingly.

Avoid overwhelming the user with saturated colors.

---

# Dark Mode Compatibility

Dark mode is planned for a future version.

All components should be designed using semantic design tokens.

Avoid hardcoded color values.

Dark mode should feel inspired by:

- Aurora Borealis
- Forest at Night
- Calm Technology

Avoid pure black backgrounds.
Prefer deep green-tinted surfaces.
